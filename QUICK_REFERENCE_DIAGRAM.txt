┌──────────────────────────────────────────────────────────────────────────────┐
│                   🎭 USER ROLE COMPARISON (Real Examples)                    │
└──────────────────────────────────────────────────────────────────────────────┘

    Scenario: "I want to see all customer invoices"
    ═══════════════════════════════════════════════
    
    👨‍💼 Admin:  Login at /admin → Sales → Invoices → See ALL invoices ✅
    👤 Client: Login at /clients → Invoices → See ONLY my invoices 👁️
    
    
    Scenario: "I want to add a new lead"
    ════════════════════════════════════
    
    👨‍💼 Admin:  Login at /admin → Leads → New Lead → Fill form → Save ✅
    👤 Client: No option to add leads ❌ (clients don't manage leads)
    
    
    Scenario: "I want to create an invoice"
    ═══════════════════════════════════════
    
    👨‍💼 Admin:  Login at /admin → Sales → Invoices → New Invoice ✅
    👤 Client: Cannot create invoices ❌ (only receive them)
    
    
    Scenario: "I want to pay an invoice"
    ════════════════════════════════════
    
    👨‍💼 Admin:  Can mark as paid manually 👁️
    👤 Client: Can pay online through gateway ✅
    
    
    Scenario: "I want to view sales reports"
    ════════════════════════════════════════
    
    👨‍💼 Admin:  Login at /admin → Reports → Sales → See graphs ✅
    👤 Client: No reports section ❌

    Problem: "Invalid email or password" at /admin
    ═══════════════════════════════════════════════
    Cause:   You're using CLIENT credentials
    Fix:     Use STAFF credentials instead
    
    
    Problem: "I don't see Leads menu"
    ══════════════════════════════════
    Cause:   You're logged into /clients portal
    Fix:     Logout and login at /admin portal
    
    
    Problem: "I can only see my own invoices"
    ══════════════════════════════════════════
    Cause:   You're logged in as CLIENT
    Fix:     You need ADMIN login to see all invoices
    
    
    Problem: "Where is the Kanban board?"
    ══════════════════════════════════════
    Cause:   You're in wrong portal OR wrong view
    Fix:     Login at /admin → Leads → Click "Kanban" button
    
    
    Problem: "Currency shows $ instead of ₹"
    ════════════════════════════════════════
    Cause:   Currency not updated in database
    Fix:     Run update_currency_symbol.php tool
