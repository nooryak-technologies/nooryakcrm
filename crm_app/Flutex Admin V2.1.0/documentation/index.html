Install Flutex Admin/Staff Api Module

After Extracting the zip file you got from codecanyon, locate "flutex_admin_api.zip" file.

Install API Module on your Perfex CRM

Step 1 :
Open your Perfex CRM admin panel and got to: Setup > Modules, Then Click on "Choose file" to browse the file from your computer and click on "Install" Button.

Step 2 :
After Installation is complete click on "activate" button.

Step 3 :
Enter your Envato Username and Purchase code then click "save" button. (Where to find purchase code?)

Step 4 : Now you're all set, and you can navigate to your api module settings to setup your Flutex app options.

Important! (Not Mandatory)
In some servers, the Authorization header won't processed so if you faced this issue when running the app you'll need to fix that by adding these lines to your ".htaccess" file on your main Perfex CRM path. if it not exist then please create new file named ".htaccess" in your main Perfex CRM path and add these line to it. 

                            RewriteEngine On
                            # Handle Authorization Header
                            RewriteCond %{HTTP:Authorization} .
                            RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

Setup API Settings

- Enable Admin/Staff Login

From your modules page click on "Flutex Admin/Staff API > Settings".

On this page you can enable/disable admin/staff login within Flutex app.

- Setup Firebase Service File

    Step 1 :
    Open Firebase website and click on "Go to console" button. (Click here to open Firebase website)

    Step 2 :
    Create a new Firebase project.

    Step 3 :
    Enter your desired firebase project name and click on next.

    Step 4 :
    Wait till it's finished setting up then click on "Continue" button.

    Step 5 :
    Now as your project ready head to "Project settings" from the top left gear icon.

    Step 6 :
    Navigate to "Service accounts" tab, then click on "Generate new private key" button and from the popup dialog click on "Generate Key" button.

    Step 7 :
    You'll get a JSON format file, open it on any text editor and copy all it's contents.

    Step 8 :
    Open your Perfex CRM dashboard and navigate to Settings > Flutex Admin Settings. then Paste the contents to "FCM service file content" field and click "save settings" button.

    That's all! and you can now procceed setting up Flutex Admin/Staff Flutter App.

Install Flutter on Windows

  1. Download Flutter SDK
  2. Extract the downloaded Flutter zip file to a location on your machine. For example, ‘C:\flutter’.
  3. Now set your enviournment variable, From the Start search bar in , type ‘env’ and select Edit environment variables for your account.
  4. Under User variables check if there is an entry called Path, Click on Edit.new Dialog open from it click on new and copy full path to flutter\bin as its value.
  5. Verify Flutter Installation, Open a new Command Prompt and run ‘flutter doctor’ to check for any dependencies that need to be installed or configured..

Please follow this video for step by step installation guide for Mac.

Import Project in Android Studio

  1. Open Android Studio > Open > navigate to the app path and select it then click Ok
  2. Locate "pubspec.yaml" file in your main project files and click "pub get"

Connect Flutex Admin/Staff App to Perfex CRM

Open Android Studio > lib > core > utils > url_container.dart, and replace domainUrl value with your Perfex CRM URL.

For iOS, to change label that is shown below ios app icon, open ios > Runner > Info.plist inside that CFBundleName change that string as shown in below fig.

- Change Package Name

  1. In the Android pane, click on the little gear icon.Uncheck/Deselect the Compact Empty Middle Packages option.
  2. Your package directory will now be broken up in individual directories.
  3. Individually select each directory you want to rename, and: Right-click it Select Refactor Click on Rename current In the Pop-up dialog.
  4. Enter the new name and hit Refactor.Allow a minute to let Android Studio update all changes.
  5. Now press ctrl + shift + R and replace old packagename with your new packagename

- Setup Firebase

  1. Open your Terminal and Install Firebase CLI using this command:
    2.                                 npm install -g firebase-tools
  2. Login to firebase in your Terminal using this command:
    3.                                 firebase login
  3. From any directory, run this command:
    4.                                 dart pub global activate flutterfire_cli
  4. Then, at the root of the Flutex app project directory, run this command:
    5.                                 flutterfire configure
  5. Use arrow keys to Select your project from the list then press Enter, it'll show list for supported platforms, choose Android and IOs using space and arrow keys then press Enter.
  6. This automatically registers Flutex app per-platform with Firebase and adds a lib/firebase_options.dart configuration file to the Flutter project.

    7. That's all!

- Change App Colors

Open Android Studio > lib > core > utils > color_resources.dart, and replace values with your desired colors.

- Change App Icon

Open Android Studio > app > res > mipmap > ic_launcher.png, and replace images with the same name.
